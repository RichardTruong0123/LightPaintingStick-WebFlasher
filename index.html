How to Flash

The complete process takes only a few minutes.

1

Connect

Connect the ESP32-S3 to your computer using a USB cable that supports data transfer.

2

Start Installer

Click Flash Firmware and select the ESP32-S3 serial device from the browser's port list.

3

Flash

Follow the ESP Web Tools dialog until the firmware installation completes.

⚠ Before flashing

Close Arduino Serial Monitor, PlatformIO, PuTTY, or any other application that may be using the ESP32 serial port. Use a known-good USB data cable and connect directly to the computer whenever possible.

Troubleshooting

Common solutions for browser flashing problems.

Failed to download manifest

First open the manifest directly in your browser:

https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/manifest.json

If the browser cannot display the JSON, check that the file is named exactly manifest.json and is located in the repository root.

Also verify that every firmware path in the manifest exactly matches the GitHub Pages path.

The ESP32 does not appear in the port list

Try the following:

  1. Disconnect the board.
  2. Close Serial Monitor.
  3. Close PlatformIO.
  4. Reconnect the USB cable.
  5. Try another USB port.
  6. Try another known-good USB data cable.
  7. Check Windows Device Manager.

If Windows does not recognize the USB serial device, the appropriate USB serial driver may need to be installed.

Flashing starts but fails

Disconnect other programs from the serial port and retry.

If necessary, manually place the ESP32-S3 into bootloader mode before clicking Flash Firmware.

How do I manually enter bootloader mode?
  1. Disconnect USB if necessary.
  2. Press and hold the BOOT button.
  3. Press and release RESET.
  4. Continue holding BOOT briefly.
  5. Release BOOT.
  6. Return to the installer and select the ESP32-S3 serial port.

The exact button labels and sequence can vary slightly by Waveshare board revision.

GitHub Pages shows 404

Verify that GitHub Pages is enabled for the correct branch and directory.

For a standard repository deployment, the URL should look like:

https://YOUR-USERNAME.github.io/LightPaintingStick-WebFlasher/

Make sure index.html is in the selected Pages directory.

Firmware files return 404

Test each BIN file by opening its URL directly.

For example:

https://YOUR-USERNAME.github.io/LightPaintingStick-WebFlasher/firmware/LightPaintingStick.ino.bin

If the file cannot be accessed directly, ESP Web Tools cannot download it either.

The website was updated but I still see the old version

GitHub Pages and your browser can both cache resources.

Try:

  1. Hard refresh the page.
  2. Open a private/incognito window.
  3. Clear cached site data.
  4. Wait for GitHub Pages deployment to finish.
